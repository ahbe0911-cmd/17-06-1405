# زعفران گرام · Zaffran Gram

زعفران گرام یک کلاینت غیررسمی و متن‌باز تلگرام برای اندروید است که بر پایهٔ
[Forkgram](https://github.com/Forkgram/TelegramAndroid) و کد رسمی
[Telegram for Android](https://github.com/DrKLO/Telegram) توسعه داده می‌شود.

> این پروژه در مرحلهٔ پایه‌گذاری است و هنوز نسخهٔ قابل استفاده برای ورود منتشر نشده است.

## اصول پروژه

- نام، شناسهٔ نصب و نشان مستقل: `org.zaffrangram.messenger`
- API ID و API Hash شخصی هر کاربر فقط هنگام ورود در خود دستگاه دریافت می‌شود.
- هیچ API ID/Hash در سورس، GitHub Actions یا فایل APK قرار نمی‌گیرد.
- اطلاعات ورود در مرحلهٔ بعد با رمزنگاری مبتنی بر Android Keystore نگهداری می‌شود.
- قابلیت آزمایشی WebSocket فورک حفظ می‌شود؛ استفاده از رله‌های عمومی به سرور شخصی نیاز
  ندارد، اما اپراتور رله می‌تواند IP و فرادادهٔ اتصال را مشاهده کند.
- انتخاب فونت و بهبود رابط استوری پس از تکمیل و آزمون مسیر امن ورود انجام می‌شود.
